## **Getting Started**

### 1. Clone the repository
```bash
git clone https://github.com/annugit1655/Customer-Behaviour-Analysis-with-CLTV.git
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Reproducing the Analysis (Optional)
The project has already been created, and the notebooks contain the complete analysis workflow.

To reproduce the analysis from scratch, open:
```bash
run all notebooks 01-Data-Preparation.ipynb to 09-CLTV-Probabilistic-models.ipynb
```
